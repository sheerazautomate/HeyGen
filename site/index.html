What changed from pilot to personal pro?

Limits removed: 24KB→10MB, 30s→600s, 1920px→4096px, 1080p→4K, 30fps→60fps, standard→high quality, MP4 only→MP4/WebM/MOV, 256MB→2GB. Network enabled (external images, fonts, audio, video allowed). Private repo (videos are private releases). No approval list, no 2/day quota. Renderer upgraded to 4 CPUs, 8GB RAM, 15min timeout. UI adds quality/fps/format/variables editor + live preview.

How do I use external assets?

Just use normal URLs in your HTML: <img src="https://...">, Google Fonts links, audio/video tags, fetch(). In pilot these were blocked offline. In pro mode, Docker has network access, so they load during render. Keep assets CORS-friendly.

What about variables?

If your composition has data-composition-variables, the studio auto-detects them and shows an editor. You can override at render time — same HTML produces many videos. Variables are injected via window.__hyperframes.getVariables override.

Is it really private?

Yes if your GitHub repo is private (make it private in Settings). Releases are private then. The studio itself is still static site — host it privately or on localhost via python -m http.server. No public gallery — only you see your releases when logged into GitHub.
